# STEPの呼び方をどちらにするか（判断メモ）

> IPL標準フロー v1.1　対象：標準化チーム・IPL担当

## 1. 結論（提案）

**STEP の名前と番号は、社内で共有済みのフロー（STEP0 目的設定 〜 STEP8 学習・標準化）に統一する。**
発明塾の言葉（エッジ情報、ファーストユーザー、企画骨子、課題‐解決ロジックツリーなど）は、各 STEP の中の「やり方（手順）」の名前として使う。

## 2. 比べた選択肢

| 選択肢 | 中身 | よい点 | 気になる点 |
| --- | --- | --- | --- |
| A（提案） | 共有済みフローの名前を使い、発明塾の言葉は手順の中で使う | 再共有が不要。名前が「何を作るか」で表されていて、受講経験のない人にも意味が伝わる。社内の言葉なので、社外の講座の利用条件に左右されにくい | 発明塾の流れの「入口の分かりやすさ」が STEP 名からは見えにくい |
| B | 発明塾の流れ（エッジ情報 → ファーストユーザー → 顧客価値 → …）の名前に変える | 発明塾の受講者には分かりやすい | 共有済みの図を作り直して再共有する必要がある。受講していない人には言葉がなじまない。社外の講座の言葉に社内標準が依存する |
| C | A の STEP 名に、発明塾の言葉を副題として付ける（例：STEP1 顧客価値仮説（売れる）―ファーストユーザーと困りごと） | 両方の良さを取れる | 図が長くなる。副題の付け方を決める手間 |

## 3. 根拠

- 共有済みフローと発明塾の流れは、順番の考え方がほぼ一致している。どちらも「顧客価値（売れる）を先に、売れる・勝てる・儲かるで事業を見る、仮説を立ててから調べる、外れていたら戻る」という構造になっている（発明塾式 企画術1〜3日目、企業内発明塾 紹介資料）。違いは主に**言い方**であり、**中身の順番を変える必要はない**と推測される。
- 発明塾の流れが「分かりやすい」と感じる理由は、次の3つと考えられる。いずれも STEP の中の手順として入れれば失われない。
  1. 入口が具体的（「気になる情報を1件」から始める）→ STEP1 の 1-1
  2. 顧客が具体的（「まず一社・一人」）→ STEP1 の 1-2, 1-3
  3. 企画の型が決まっている（5つのポイント）→ STEP2 の 2-1

## 4. この判断が外れる可能性（反証・別の見方）

- 利用者アンケート（STEP8）で「STEP名から何をすればよいか分からない」という声が多ければ、選択肢C（副題）に切り替える。判断の目安：パイロット利用者の3割以上が同じ指摘をした場合。
- 社内に発明塾の受講者が多く、発明塾の言葉がすでに共通語になっている部署では、B のほうが伝わる可能性がある。部署ごとの受講状況を確かめていない。
- 呼び方を統一しても、エージェントや手順書の中で両方の言葉が混ざると混乱する。対応表（[90_発明塾手法との対応.md](90_発明塾手法との対応.md)）で、言葉の対応を1か所にまとめる。

## 5. 共有済みフローについて、あわせて検討してほしい点

本手順書を書く中で、共有済みの図について気づいた点。**図は変えずに手順書の中で対応した**が、次の改訂で図に反映するかを検討してほしい。

| No | 気づいた点 | 手順書での対応 | 図に反映する案 |
| --- | --- | --- | --- |
| F1 | STEP2 の観点が「勝てる・儲かる・できそう」で、IPL の中心である**知財で守れるか**が名前に出ていない | STEP2 の 2-2 で「勝てる（守れるを含む）」として扱った | 「勝てる（守れる）」と書き添える |
| F2 | **顧客へのヒアリング**がどの STEP にも書かれていない。特許や公開情報だけでは「売れる」は確かめにくい | STEP6 の 6-4〜6-6 に入れた | STEP6 を「仮説検証・反証（ヒアリング含む）」とする |
| F3 | もどり先に「事業仮説（勝てる・儲かる・できそう）が弱い → STEP2」がない | STEP6 の 6-8 では、顧客価値が弱い場合のみ STEP1 とした | 「事業仮説が弱い → STEP2」を追加する |
| F4 | STEP7 が Go / No Go の二択で、「方向を変えてやり直す」「条件付きで進める」が見えない | STEP7 の 7-3 で No Go の中を「やめる」「方向を変える」に分けた | No Go の先に「方向転換 → STEP1」の矢印を足す |
| F5 | 「STEP1・2 は既存情報（社内含む）で立てる」と、発明塾の「エッジ情報を探す」の関係があいまい | STEP1 で「手元の情報＋1〜3日の範囲の気になる情報」と書いた | 社内で解釈をそろえる（新しい本格調査は STEP3 から、という意味でよいか） |
| F6 | STEP8 が「アンケート等で振り返り」で、**考えた経過（なぜその仮説を捨てたか等）**を残すことが書かれていない。横展開にはこちらが効く可能性がある | STEP8 の 8-2 に入れた | 「学習・標準化（振り返り・ノウハウ集）」とする |
| F7 | 「やるべきか（会社の方針との整合）」がどこにもない | STEP0 の 0-3 に入れた | 図の変更は不要（STEP0 の中身として扱う） |
