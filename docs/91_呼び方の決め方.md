# フローの形と呼び方の判断メモ

> IPL標準フロー v1.2　対象：標準化チーム・IPL担当

## 1. 結論

- **STEPの名前と番号は、社内で共有するフロー図（2026-11-13 版：STEP0 お題設定 〜 STEP8 依頼者が意思決定）に合わせる。**
- 発明塾の言葉（エッジ情報、ファーストユーザー、企画骨子、課題‐解決ロジックツリーなど）は、各STEPの中の「やり方（手順）」の名前として使う。
- フロー図にない要素（学習・標準化、できそう、事業仮説が弱いときの戻り）は、図を大きく変えずに手順書の中で補う（3章）。

## 2. 2026-11-13 版のフローの評価

### 2-1 よくなった点（残す）

| No | 変更 | 評価 | 根拠・考え方 |
| --- | --- | --- | --- |
| G1 | STEP0 を「目的設定」から「お題設定」に変えた | 残す | 事業・研究の人が自分で始めるとき、最初から「何を決めるか」は書けないことが多い。気になっていることから入れるほうが始めやすい。発明塾の「企画書はゴールではなくスタート」「手元の情報から仮説を立てる」とも合う（企画術1・2日目） |
| G2 | 仮説（STEP1・2）の後に「調査目的設定」（STEP3）を置いた | 残す | 仮説を立ててから「何を決めるか・どの仮説を確かめるか」を決めるので、調べる範囲が絞れる。発明塾の「仮説ドリブン」「網羅性を求めすぎない」とも合う（企業内発明塾 紹介資料） |
| G3 | 検証ループから STEP0 に戻らず、意思決定の後に「新たな調査へ」で STEP0 に戻す | 残す | 分かったことに結論を出して進むので、調査が終わらなくなるのを防げる。新しい疑問は次の周回に回す。案件ごとに判断の記録が残る |
| G4 | 「調査目的とずれる → STEP3」の戻りを追加 | 残す | 調べた結果が目的の外に広がったときに、目的を見直す場所がはっきりした |

### 2-2 足りない点と、手順書での補い方

| No | 足りない点 | 何が困るか | 手順書での対応 | 図への反映（提案） |
| --- | --- | --- | --- | --- |
| F1 | 「学習・標準化」の箱がなくなった | 振り返りと知見の回収が、どこで行われるか見えなくなる。横展開と標準フローの改善が止まるおそれ | STEP8 の最後に 8-8「振り返って残す」を置いた。IPL担当の相談ログの仕組み（docs/96）はフローの外側で回す | STEP8 の箱に「（振り返りを含む）」と添えるか、図の下に「案件の振り返り → 標準フローの改善」の矢印を足す |
| F2 | STEP2 から「できそう」が外れた | 自社で作れない・規制を越えられない事業を見落とすおそれ。研究部門のテーマでは特に大きい | STEP2 の 2-4 で「できそう」も必ず確かめる。事業仮説シートにも行を残した | 図は「（勝てる・儲かる）」のままでよい。説明時に「できそうを含む」と口頭で補う |
| F3 | 「勝てる・儲かるが弱い → STEP2」の戻りがない | 顧客価値は強いが勝てない・儲からない場合に、STEP1 まで戻ることになる | STEP7 の 7-9 で、必要に応じて STEP2 に戻れるとした | 「事業仮説が弱い → STEP2」を足す（任意） |
| F4 | 「守れる（知財）」が STEP2 の名前に出ていない | IPLの中心である知財の観点が見えにくい | STEP2 の 2-2 で「勝てる（守れるを含む）」として扱う | 「勝てる（守れる）」と書き添える（任意） |
| F5 | 顧客ヒアリングがどの箱にも出ていない | 公開情報だけでは「売れる」を確かめにくい | STEP7 の 7-4〜7-6 に入れた | STEP7 を「仮説検証・反証（ヒアリング含む）」とする（任意） |

### 2-3 検証ループから STEP0 に戻らないことの反証・注意

- 調べている途中で、お題そのものが成り立たないと分かる場合がある（例：前提にしていた規制が変わらないと分かった）。そのまま調査を続けると時間の無駄になる。
  - 対応：STEP7 の 7-8 で「分かったこと」として結論を出し、早めに STEP8 に進んで判断する（No Go または方向を変える）。調査を続けずに次の周回に移る。
- 「新たな調査へ」が多すぎると、案件が終わらないまま周回が続くおそれがある。
  - 対応：STEP8 の 8-7 で、新たなお題は意思決定者と合意したものだけにする。

## 3. 呼び方を共有済みの図に合わせる理由

| 選択肢 | よい点 | 気になる点 |
| --- | --- | --- |
| A（採用） | 社内で共有する図と同じなので、再共有の手間がない。名前が「何をするか」で表されていて、受講経験のない人にも伝わる。社外の講座の言葉に依存しない | 発明塾の流れの入口の分かりやすさが STEP 名からは見えにくい → STEP0 お題設定と、手順名（エッジ情報、ファーストユーザー）で補う |
| B | 発明塾の言葉を STEP 名に使う | 受講していない人に伝わりにくい。社外の講座の利用条件に左右される |

試行の振り返りで「STEP名から何をすればよいか分からない」という声が3割以上あれば、STEP名に副題を付ける案を検討する。
