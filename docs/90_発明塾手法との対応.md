# 発明塾の手法との対応表

> IPL標準フロー v1.1

発明塾の考え方を、標準フローのどのSTEPのどの手順に入れたかの一覧です。
左の列は原資料の考え方を短く要約したもので、原文の転載ではありません。発明塾の正式な手順や評価基準を示すものでもありません。

## 1. 言葉の対応

| 発明塾でよく使う言葉 | 標準フローでの場所 |
| --- | --- |
| エッジ情報（探索） | STEP1 1-1「気になる情報（エッジ情報）を1件選ぶ」 |
| ファーストユーザー（ターゲット） | STEP1 1-2, 1-3 |
| 顧客価値仮説 | STEP1（STEPの名前そのもの）、1-6 |
| 企画骨子（5つのポイント） | STEP2 2-1 |
| 売れる・勝てる・儲かる | STEP1（売れる）、STEP2（勝てる・儲かる・できそう） |
| 独占 | STEP2 2-2「この会社から買わなければならない理由」 |
| 課題‐解決ロジックツリー、トレードオフ | STEP1 1-5 |
| 仮説検索（課題の先読み） | STEP3 3-4 |

## 3. 使うときの注意（反証・別の見方）

- エッジ情報から入る方法は気づきを得るのが早い一方、最初の1件の選び方に結果が左右されやすい。STEP3〜5 で範囲を決めて確かめる手順を置き、偏りを後で検証できるようにしている。
- ファーストユーザーを一社に絞ると、その一社の事情（予算の時期、担当者の異動）に判断が引っ張られる可能性がある。候補を2〜3社残し、STEP6 で別の候補にも当てることを勧める。
- 発明塾の資料は新事業・新規研究テーマの企画を主な対象としている。「今の事業を強くする」「知財リスクを見る」が目的の場合は、STEP1・2 を軽くして STEP3〜5 に時間を寄せるほうが合う場合がある（全体像4章）。
- 本表の要約は筆者の読みであり、原資料の意図と違う可能性がある。社内展開の前に、発明塾の受講経験者に確認してもらうことを勧める。
