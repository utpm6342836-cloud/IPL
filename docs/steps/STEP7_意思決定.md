# STEP7　依頼者が意思決定（Go / No Go）

> IPL標準フロー v1.1／STEP7　（全体像：[01_全体像.md](../01_全体像.md)）

## このSTEPでやること

根拠・残る不確かさ・次の一手をそろえた**判断メモ**を作り、依頼者（意思決定者）が Go / No Go を決めます。必要に応じて、経営層に提言します。

## なぜ必要か

調べた内容の報告で終わると、何も決まりません。決める人が決められる形にするのが、このSTEPの役目です。

## 始める前にそろえるもの

- 仮説の記録・ヒアリング票（STEP6、IPL担当の確認済み）、依頼シート（STEP0 の Go／やめる条件）

## やり方

### 7-1　4つの観点を4段階で評価する（45分）

| 評価 | 意味 |
| --- | --- |
| ① 確かめた | 顧客の行動（発注・有償評価）や試験結果、ランクAの情報で裏付けがある |
| ② 有力だが未確認 | ランクBの情報で支えられているが、顧客の行動や試験では確かめていない |
| ③ 根拠不足 | ランクC・Dしかない |
| ④ 外れている証拠が優勢 | 外れている証拠のほうが強い |

- 売れる・勝てる（守れるを含む）・儲かる・できそう に付けます。
- 合計点で Go にしません。規制の壁・他社特許の壁・お金を払う人がいない、のどれかが致命的なら、ほかが高くても進めません。

### 7-2　「儲かる」を、最初の顧客から積み上げて試算する（60〜120分）

- 1社分の売上 → 社数と広がる速さ → 標準・楽観・悲観の3つの場合。
- 販売数量・単価・歩留まり・原料価格・稼働率を変えたときに、どこで赤字になるかを見ます。
- 市場全体の伸び率を、自社の売上の伸びに置き換えません。
- エージェントに頼めること：試算表の下書き、感度分析の計算。数字の前提は自分で確かめます。

### 7-3　選択肢を並べる（30分）

- 研究する／出願する／組む／買う／見送る、それぞれの費用・期間・必要な人・得られるもの。
- No Go の場合も「やめる」のか「方向を変えて STEP1 からやり直す」のかを書きます。

### 7-4　判断メモを書く（60分）

- [templates/11_判断メモ.md](../../templates/11_判断メモ.md)
- 1枚目に4つ：つまり何か／次に何をするか（誰が・いつまでに・費用）／やめる条件／まだ分からないこと。
- さらに次の4つをセットで書きます：判断の根拠／残る一番大きな不確かさ／それを消す一番小さな実験／次に判断する日。
- 確かめずに判断した部分（期限・予算で打ち切った部分）も書きます。
- 主な根拠はランクA・Bの情報（番号とURL）だけにします。

### 7-5　依頼者が決め、記録する（会議）

- 依頼者・意思決定者の判断と、出た質問・指摘を案件ファイルに記録します。
- 判断するのは依頼者・意思決定者です。エージェントやIPL担当が代わりに決めることはありません。

### 7-6　必要なら経営層へ提言する（準備60分＋会議）

- 全社の方針に関わる場合、複数の事業部にまたがる場合、大きな投資が必要な場合などに、判断メモの1枚目を使って提言します（提言の基準は社内で決めてください）。

## 発明塾のコツ

- 企画を見直すときは「ファーストユーザー」「顧客価値の仮説」「ビジネスモデル」「必要な社内外の資源」「知財の戦略」の観点で確かめる（「発明塾」全6回のワークショップ概要）。
- 行き詰まったら方向転換（Pivot）をくり返して育てる（企業内発明塾 紹介資料）。No Go は「やめる」だけでなく「方向を変える」も選べます。

## できあがるもの

- 判断メモ、意思決定の記録

## 次に進む前のチェック

| 誰が | 確認すること | だめなら |
| --- | --- | --- |
| 意思決定者 | つまり何か・次に何をするか・やめる条件・まだ分からないことがそろっているか。主な根拠がランクA・Bか | STEP6 |

## 困ったら

- 依頼者から「もう少し調べて」と言われた → 何が分かれば判断できるのかを具体的に聞き、STEP3 に戻る。答えがどうであれ判断が変わらない項目なら、調べずに進める提案をする。

## 根拠

- 発明塾×IPL 実践手順書 v1.0 第12〜14章（社内）
- 「発明塾」全6回のワークショップ概要紹介、企業内発明塾 紹介資料（社内保管・社外秘）
- スキル `ipl-navigator`（判断メモ）
