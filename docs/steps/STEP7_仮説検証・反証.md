# STEP7　仮説検証・反証

> IPL標準フロー v1.2／STEP7　（全体像：[01_全体像.md](../01_全体像.md)）

## このSTEPでやること

集めた情報と、**顧客に仮説を持ち込んだヒアリング**の結果で、仮説を「残す・直す・捨てる・保留」に分け、分かったこと・まだ分からないことを整理して、次に何をするか（STEP4・3・1 に戻るか、STEP8 に進むか）を決めます。

## なぜ必要か

都合のよい情報だけを集めると、間違った仮説のまま意思決定に進んでしまいます。また、特許や公開情報だけでは「顧客が本当にお金を払うか」は分かりません。

## 始める前にそろえるもの

- 整理表・マップ（STEP6）、情報リスト（STEP5）、事業仮説シート（STEP2）

## やり方

### 7-1　仮説ごとに、支える情報と外れている証拠を並べる（仮説あたり15分）

- 情報リストの「H2+」「H2−」で分けます。外れている証拠が1つもない仮説は、探し方が足りない可能性があります。

### 7-2　反対の立場から見てもらう（30〜60分）

- 自分以外の人（同僚、IPL担当）に「反対の立場で見て」と頼みます。
- 人がいないときは、エージェントに「この結論に反対する立場で、外れている証拠の候補と見落としを挙げて」と頼みます。エージェントの指摘はランクDの候補として扱い、元の資料で確かめます。

### 7-3　よくある思い込みを確かめる（15分）

- [ ] 特許が見つからない＝誰もやっていない、と決めつけていない（秘密・未公開・検索漏れ）
- [ ] 出願が多い＝強い、と決めつけていない
- [ ] 最近の出願が減って見えるのは、未公開のためではないか確かめた
- [ ] 別の技術で同じ困りごとが解決されていないか確かめた
- [ ] 直接のお客様とその先のお客様の両方を確かめた

### 7-4　ヒアリング用の提案書を作る（2〜4時間）

- エージェントに頼めること：提案書の下書き、想定される質問と反論の洗い出し。自分でやること：内容の確認と、ヒアリング本番。
- 漠然と聞くと、漠然とした答えしか返ってきません。具体的で尖った仮説を1〜2枚の提案書にして持ち込みます。
- 入れるもの：困りごとの仮説、トレードオフ、解決のしかた、比較の相手、見せられる具体物（サンプル・試作・仕様案・概算の価格など）。
- 話を聞く相手は、STEP5 で特許・論文から見つけたキーマン（発明者・共同研究先）も候補にします。

### 7-5　自分で聞きに行く（1件60分＋記録30分）

- 自分で立てた仮説は、自分で確かめます。他の人に代わりに聞いてもらうと、相手の質問に答えられず、本音が聞けないことがあります（営業担当などに同席してもらうのはかまいません）。
- 説明は短くして、次を聞きます：①最近の具体的な不満、②今の代わりの手段、③入れない理由、④お金を払う人・予算、⑤有償の評価に進めるか。
- 「欲しいですか」だけの質問や、ほめ言葉だけで「需要がある」と判断しません。
- **「違う」と言われたことも大事な情報**として記録します。
- 聞いた事実と、自分の解釈を別の欄に書きます。秘密保持・個人情報の扱いに注意します。
- [templates/10_ヒアリング票.md](../../templates/10_ヒアリング票.md)

### 7-6　証拠の強さを分ける（15分）

| 強さ | 例 |
| --- | --- |
| 強 | 発注、有償の評価、支払条件の提示 |
| 中 | 予算と導入の手順が確認できた共同評価 |
| 弱 | アンケートでの好意的な回答、こちらの推測 |

### 7-7　仮説を「残す・直す・捨てる・保留」に分ける（30分）

- [templates/09_仮説の記録.md](../../templates/09_仮説の記録.md) に、判断と「なぜそうしたか」「なぜ次にそれを調べるか」を書きます。この欄は、次の人があなたの考え方を学ぶための一番大事な欄です。
- 先に見つかった似た例（特許・製品・論文）と自分の仮説との違いを書き、その違いを広げる方向で仮説を直します。

### 7-8　分かったこと・まだ分からないことを整理し、分かったことに結論を出す（30分）

- STEP3 で選んだ仮説ごとに、次の3つに分けます。
  1. 分かったこと：結論（残す・直す・捨てる）と、その根拠（ランクA・Bの情報）
  2. まだ分からないこと：なぜ分からないか、確かめるにはどうすればよいか
  3. 新しく出てきた疑問：今回の調査目的の外にあるもの
- **分かったことには、ここで結論を出します。** まだ分からないことがあっても、分かったことの結論は先送りしません。
- 新しく出てきた疑問は、今回の調査を広げずに、STEP8 の後で「新たなお題」として STEP0 から回します。

### 7-9　次に進むか戻るかを決める（15分）

| 気づいたこと | 次 |
| --- | --- |
| 判断に使える事実（Fact）が足りない | STEP4（調査設計を見直す） |
| 調べたことが調査目的とずれていた | STEP3（調査目的を見直す） |
| 顧客の困りごと・価値が弱い | STEP1 |
| 勝てる・儲かるの仮説が弱い | STEP2（共有済みの図にはない戻り先。必要に応じて使う） |
| 判断に足る事実がそろった（STEP3 の Go／やめる条件で判断できる） | IPL担当の確認を受けて STEP8 |

- お題そのものがずれていたと分かった場合も、ここでは STEP0 に戻りません。分かったことを整理して STEP8 で判断し（例：No Go、方向を変える）、新しいお題として STEP0 から回します。

### 7-10　IPL担当に見てもらう（30〜60分）【確認ポイント②】

- 仮説の記録・ヒアリング票・主な根拠（ランクA・B）を見せ、根拠が足りているか、反証を探したかを確認してもらいます。

## 発明塾のコツ

- ある程度調べたら、仮説を提案書にまとめてヒアリングに行く。具体的で尖った仮説を持ち込むほど、得られる情報が変わる。「違う」と言われたことも情報になる（情報探索術7日目）。
- 自分で立てた仮説は自分で確かめる。直接の反応で、仮説の立て方と情報の選び方が上達し、話を聞いた相手がよい相談相手になることもある（同7日目）。
- 先に見つかった例との違いを考えることで、アイデアを企画へ育てる（「発明塾」全6回のワークショップ概要）。
- よい仲間とよい議論：人によって見え方が違うことを、思い込みを越えるために使う（企業内発明塾 紹介資料）。

## できあがるもの

## 次に進む前のチェック

| 誰が | 確認すること | だめなら |
| --- | --- | --- |
| 自分 | 外れている証拠を探した記録がある。ヒアリングの事実と解釈が分かれている | 7-1〜7-5 |
| IPL担当【確認ポイント②】 | 判断の主な根拠がランクA・Bか。反証を探したか。分かったことに結論が出ているか | STEP4・3・1 |

## 困ったら

- ヒアリング先が見つからない → STEP5 で見つけた発明者・共同研究先、展示会、業界団体を候補にし、IPL担当・営業に相談する。
- 仮説が全部崩れた → 失敗ではありません。崩れたこと自体が分かったことです。7-8 で整理して STEP8 で判断し、聞いた話から見えた新しい困りごとを、新たなお題として STEP0 から回します。顧客だけを変えればよい場合は STEP1 に戻ります。
