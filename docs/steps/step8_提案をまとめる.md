# Step 8　提案をまとめる

> IPL標準フロー v1.0／Step 8　（全体像：[00_全体像.md](../00_全体像.md)）

## 目的

研究する・出願する・組む・買う・見送るを比べ、判断の根拠・残る最大の不確かさ・それを消す最小の実験・次の判断日をそろえて、意思決定者が決められる判断メモにする。

## 始める条件

- 予想の記録（Step 7）があり、やめてよい条件のどれかを満たしている。

## 手順

### 8-1　選択肢を並べる（30分）

- 研究する／出願する／組む／買う／見送る（＋検証を続ける）を並べる。
- それぞれの費用・期間・必要な人・得られるもの・失うものを書く。

### 8-2　6つの観点を4段階で評価する（45分）

| 評価 | 意味 |
| --- | --- |
| ① 確かめた | 顧客の行動（発注・有償評価）や試験結果、ランクAの情報で裏付けがある |
| ② 有力だが未確認 | ランクBの情報で支えられているが、顧客行動や試験では確かめていない |
| ③ 根拠不足 | ランクC・Dしかない |
| ④ 外れている証拠が優勢 | 外れている証拠のほうが強い |

- 売れる・勝てる・儲かる・できる・守れる・やるべき の6観点それぞれに付ける。
- 合計点で機械的に Go としない。規制の壁・FTOの問題・お金を払う人がいない、のどれかが致命的なら、他が高くても進めない。

### 8-3　儲かるかを、初期顧客から積み上げて試算する（60〜120分）

- まず1社分：年間使用量 × 採用率 × 自社の単価。
- 対象社数・地域・導入の速さを掛けて、獲得できる売上のシナリオを作る。市場全体の成長率を自社の売上成長率に置き換えない。
- 売上高・売上総利益・営業利益を分け、設備投資・運転資金・歩留まり・価格の下落・量産の立ち上げ時期を書く。
- 販売数量・単価・歩留まり・原料価格・稼働率の5つを振り、標準・楽観・悲観の3ケースで損益分岐を見る。
- 「高付加価値だから儲かる」という推論はしない。

### 8-4　勝てる・守れるの根拠を3つに絞る（30分）

- 顧客の成果での優位、まねしにくさ（製法・ノウハウ・データ・設備）、特許・営業秘密・契約、顧客認証・供給網・販路、切り替えにかかるコスト、競合の対応力 から、根拠の強い3つを選ぶ。
- 「自社に出願の余地がある」と「他社の権利を侵害せずに実施できる（FTO）」は別の問題として書く。FTOは対象製品・国・時点を特定して、専門家の判断を得る。

### 8-5　判断メモを書く（60分）

- ひな形：[templates/10_判断メモ.md](../../templates/10_判断メモ.md)
- 1枚目に「つまり何か（結論）」「次に何をするか」「やめる条件」「まだ分からないこと」を置く。
- 主な根拠はランクA・Bの情報番号とURL。C・Dは「まだ分からないこと」に入れる。
- 確かめずに判断した部分（期限・予算で打ち切った部分）を明記する。

### 8-6　提案を4つの形のどれかにする（15分）

| 提案 | 条件の目安 |
| --- | --- |
| Go | 顧客の行動・競争の条件・採算・実行計画が、次の段階の投資を説明できる |
| 検証を続ける | まだ確かでないが、安い実験で消せる |
| Pivot（方向転換） | 顧客・価値・技術・価格・販路のどれかを変える |
| Stop | 買わない確かな証拠、避けられない壁、採算が合わない |

- どの提案でも「判断の根拠」「残る最大の不確かさ」「それを消す最小の実験」「次の判断日」の4つをセットで書く。

### 8-7　意思決定者に説明し、記録する（会議時間）

- 意思決定者の判断と、そのときの質問・指摘を案件ファイルに記録する。

## 発明塾の使いどころ

- 企画提案に必要な項目として「ファーストユーザー」「顧客価値仮説」「ビジネスモデル」「必要な外部・内部の資源」「知財戦略」の観点から見直す（全6回ワークショップ概要の第5回の内容を要約）。8-2〜8-4 はこれを6観点で確かめる形にしている。
- 他でもよいなら価格競争になるため、「差別化」ではなく「独占」を最初から考え、知財戦略を企画に組み込む（企業内発明塾 紹介資料）。8-4 で守れるの根拠を独立に書くのはこのため。
- 行き詰まったら方向転換（Pivot）をくり返して育てる（企業内発明塾 紹介資料）。Stop だけでなく Pivot を提案の形として持つ。

## できあがるもの

- 判断メモ（1枚目に結論・次の行動・やめる条件・まだ分からないこと）
- 5年程度の簡易損益と感度分析（儲かるの根拠として）

## チェックポイント

| 確認する人 | 確認すること | だめなら |
| --- | --- | --- |
| 意思決定者 | つまり何か・次に何をするか・やめる条件・まだ分からないことがあるか。主な根拠がランクA・Bか | Step 7 に戻る |

## よくある失敗

- 調べた内容の報告書になり、「何を決めてほしいか」が書かれていない。
- 市場規模の大きさを「儲かる」の根拠にする。
- FTOの調査をしていないのに「リスクは低い」と書く。

## 根拠

- 発明塾×IPL 実践手順書 v1.0 第11〜14章（勝てる・儲かる・できそう・4軸統合）（社内）
- 「発明塾」全6回のワークショップ概要紹介（社内保管・社外秘）
- 企業内発明塾 紹介資料（社内保管・社外秘）
- スキル `ipl-navigator`（判断メモのひな形）、`market-entry-strategy`（6観点への拡張）
