# STEP3　調査設計

> IPL標準フロー v1.1／STEP3　（全体像：[01_全体像.md](../01_全体像.md)）

## このSTEPでやること

「テーマで検索する」のではなく、**「仮説 → 確かめるのに必要な情報 → 調べる場所 → 検索のしかた」**の順で調べ方を決めます。外れている証拠の探し方と、調べるのをやめる条件も先に決めます。

## なぜ必要か

テーマ名のキーワードで検索すると、数千件の特許が出てきて、どれを読めばよいか分からなくなります。仮説から逆算すれば、読む量を減らせます。

## 始める前にそろえるもの

- 事業仮説シート（STEP2、ID付き、一番あやしい仮説に印）

## やり方

### 3-1　仮説ごとに「確かめるのに必要な情報」を書く（仮説あたり15分）

- 例：H2「既存の薄型電極は長時間つけると剥がれる」→ 必要な情報＝既存製品の仕様、剥がれに関する論文、剥がれ対策の特許の出願の動き。
- 印を付けた仮説から順に並べます。全部を同じ深さで調べません。

### 3-2　調べる場所を決める（仮説あたり10分）

| 情報 | 主な場所（無料） |
| --- | --- |
| 日本の特許 | J-PlatPat https://www.j-platpat.inpit.go.jp/ |
| 海外の特許・ファミリー | Espacenet https://worldwide.espacenet.com/ ／Google Patents https://patents.google.com/ |
| 論文・研究者 | J-GLOBAL https://jglobal.jst.go.jp/ ／Google Scholar https://scholar.google.com/ |
| 日本の上場企業 | EDINET https://disclosure2.edinet-fsa.go.jp/ ／各社のIRページ |
| 米国の上場企業 | SEC EDGAR https://www.sec.gov/search-filings |
| 規制・統計 | 対象地域の公的機関のサイト（基準日と条件を記録） |
| 顧客の本音 | ヒアリング（STEP6）。公開情報では分からないことが多い |

- 社内で契約している有料データベースがあれば、IPL担当に使い方を聞きます。

### 3-3　検索を3つの層に分ける（30分）

| 層 | 中身 | 例 |
| --- | --- | --- |
| A：顧客の課題・用途 | 何に困っているか | 装着の違和感、品質の安定 |
| B：解決のしかた・技術 | どう解決するか | 接着、伸縮、湿度の制御 |
| C：会社・製品 | 誰がやっているか | 会社名、製品名、提携先 |

- A だけ、B だけ、A×B で件数を比べると、「その技術を別の課題に使っている会社が多い」などが見えることがあります（見えたことは予想として扱います）。

### 3-4　検索式の案を作る（仮説あたり30〜60分）

- 同じ意味の言葉、広い言葉・狭い言葉、英語を書き出します。
- 特許分類（IPC・FI・Fタームなど）も使います。分からなければIPL担当に聞きます。
- 気になる特許の「課題」やトレードオフから、まだ表に出ていない課題を予想し、その言葉で検索するのも有効です。
- エージェントに頼めること：同義語・英語・特許分類の候補出し。

### 3-5　検索式を確かめる（30分）

- すでに知っている代表的な特許が、その検索式で出てくるか。
- 出てきた中から20件ほど見て、関係ないものの割合を記録します。
- 検索した日、件数、使ったデータベースを記録します。

### 3-6　外れている証拠の探し方を書く（仮説あたり15分）

- 例：「今の手段で十分」という顧客の声、すでに解決したという他社の製品や特許、失敗した事業の記事、規制で使えない可能性。
- 「特許が見つからない」ときは、秘密にしている・まだ公開されていない（出願から公開まで原則1年半）・検索式の漏れ、のどれかを確かめる方法も書きます。

### 3-7　やめる条件と時間の上限を書く（10分）

- 仮説ごとに「ここまで分かったらやめる」「何時間まで」を書きます。
- [templates/06_調査計画.md](../../templates/06_調査計画.md)

## 発明塾のコツ

- 課題を先読みして検索する（仮説検索）。特許の課題とトレードオフに注目する（企業内発明塾 紹介資料）。
- 仮説が変わるたびに大きな母集団を作り直すのは、知識と時間が必要（発明塾式 企画術2日目）。本フローでは、仮説を確かめるのに必要な範囲だけ調べ、検索式を記録して作り直しやすくします。

## できあがるもの

- 調査計画（仮説ID・必要な情報・場所・検索式・外れている証拠の探し方・やめる条件・時間の上限）

## 次に進む前のチェック

| 誰が | 確認すること | だめなら |
| --- | --- | --- |
| 自分 | すべての仮説に「外れている証拠の探し方」と「やめる条件」がある | 3-6, 3-7 |
| IPL担当（検索式を使う場合） | 代表的な特許が拾えているか | 3-4 |

## 困ったら

- 検索結果が多すぎる・少なすぎる → 検索式と件数をエージェントに見せて理由の候補を聞き、IPL担当に確認する。
