# STEP5　情報探索

> IPL標準フロー v1.2／STEP5　（全体像：[01_全体像.md](../01_全体像.md)）

## このSTEPでやること

調査計画に沿って情報を集め、1件ごとに**出典・取得日・確かさのランク**を付けて、誰が見ても元の資料にたどれる情報リストを作ります。

## なぜ必要か

出典のない情報は、判断の場で「それは本当？」と聞かれたときに答えられません。AIの要約も間違えることがあるため、元の資料にたどれることが必要です。

## 始める前にそろえるもの

- 調査計画（STEP4）

## やり方

### 5-1　調査計画の順に集める（計画の時間上限まで）

- 調査計画（STEP4）で決めた順に、一次情報（特許公報、論文、決算資料、会社の発表原文）を優先して集めます。ニュースやまとめ記事しかないときは、元の資料を探します。

### 5-2　1件ごとに情報リストに書く（1件5〜10分）

- [templates/08_情報リスト.csv](../../templates/08_情報リスト.csv)
- 出典（URL・特許番号など）がない行は作りません。
- エージェントに頼めること：特許や論文の要約、表への書き写しの下書き。自分でやること：元の資料を開いて内容と番号を確かめること（エージェントは存在しない特許番号を出すことがあります）。
- 特許は、優先日・出願日・公開日を分けて書き、権利の状態（審査中・登録・消滅など）も書きます。
- 「関係する仮説ID」の欄に、支える情報なら「H2+」、外れている証拠なら「H2−」と書きます。

### 5-3　大事な特許は「人・技術・権利」の3つの見方で読む（1件30〜60分）

| 見方 | 読むところ | 分かること（予想） |
| --- | --- | --- |
| 技術 | 課題・解決手段・実施例・効果 | 研究の成果か、欲しい技術の先取りか |
| 人 | 発明者、共同発明者、共同出願先（大学・他社） | キーマン、社外の共同研究先。ヒアリング先の候補にもなる |
| 権利 | 請求項、出願した国、審査の経過 | どの範囲・どの国で権利を欲しがっているか |

- 大事な特許は隅々まで読み、同じ発明者・同じ会社の関連特許も合わせて読みます。
- エージェントや分析ツールは、読む順番の優先付けと関連特許の洗い出しに使います。ツールの出力だけで結論にしません。

### 5-4　確かさのランクを付ける（1件1分）

| ランク | 条件 |
| --- | --- |
| A | 元の資料を人が開いて確かめた |
| B | 元の資料だがAIが読んだだけ。または独立した記事が2つ以上 |
| C | まとめ記事が1つだけ |
| D | 出典を確かめられない（出典のないAIの回答、うわさ） |

- AIが要約しただけの情報は最高でもB。自分で元の資料を開いて確かめたらAにします。

### 5-5　1日の終わりに「今日の結論」を1行書く（10分）

- 集めるだけで1日が終わらないよう、その日の時点で仮説がどう変わったかを書きます。

## 発明塾のコツ

- 事業機会の仮説を立てるには「人」「技術」「権利」の3つの見方の分析が必要。うまく読めば、技術開発の意図・キーマン・事業の意図が見えてくる（企業内発明塾 紹介資料）。
- すべての特許を読む必要はないが、重要な特許は隅々まで読む。ツールは優先付けと関連特許の抽出に使う（技術マーケティングQ&A 3日目）。

## できあがるもの

- 情報リスト（全行に出典・取得日・ランク・関係する仮説ID）

## 次に進む前のチェック（自分で）

- [ ] すべての行に出典・取得日・ランクがある
- [ ] 大事な特許は、自分で元の公報を開いて確かめた
- [ ] 外れている証拠（−）の行が1つ以上ある

## 困ったら

- 特許の請求項が読めない → エージェントに構成要素に分けてもらい、IPL担当に確認する。
- 外れている証拠が見つからない → 探し方（STEP4 の 4-6）をIPL担当と見直す。見つからないことは、仮説が正しい証拠になりません。

## 根拠

- スキル `ipl-evidence`（共通の表、確かさのランク）
- 企業内発明塾 紹介資料（社内保管・社外秘）
