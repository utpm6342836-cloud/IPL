# はじめに：このフローを読むあなたへ

> IPL標準フロー v1.1　（全体像：[01_全体像.md](01_全体像.md)）

## このフローは誰のためのものか

事業部門（SBU）や研究開発部門で、新しい事業・製品・研究テーマを考えている**あなた自身**のためのものです。
IPL担当（知財）に調査を「お願いする」ためのものではなく、**あなたが自分で仮説を立て、確かめ、決めるための手順書**です。

IPランドスケープ（IPL）とは、特許などの知財情報と、市場・顧客・競合などの事業情報を組み合わせて、事業や研究の判断に使うことです。特許の専門家でなくても、手順に沿えば進められるように書いています。

## なぜ自分でやるのか

- 顧客や技術のことを一番知っているのは、あなたです。知財担当だけで「売れる」とは言い切れません。
- 自分で立てた仮説は、自分で確かめるのが一番早く、確かです。人に頼んだ調査結果だけでは、顧客に質問されたときに答えられません。
- 調査を依頼して待つより、手元の情報でまず仮説を書き、足りない部分だけ調べるほうが、時間がかかりません。

## 一人でやるわけではない

| 時期 | あなたの進め方 | 相手 |
| --- | --- | --- |
| 2026年度 | IPL担当と一緒に進めながら、仮説の立て方と確かめ方を身につける | IPL担当（手順書を使って伴走） |
| 2027年度〜 | AIエージェントとチャットしながら自分で進める。分からない点はIPL担当に相談する | AIエージェント（手順書を読み込んだもの）、IPL担当 |

どちらの時期も、次の2か所ではIPL担当に見てもらうことを標準にします（品質を保つため）。

1. **調べ始める前**（STEP2が終わったとき）：目的・仮説・調べ方がずれていないか
2. **決める前**（STEP6が終わったとき）：根拠が足りているか、反証を探したか

## 読み方

1. まず [01_全体像.md](01_全体像.md) で、STEP0〜8 の流れをつかんでください（5分）。
2. 今いるSTEPの手順書（[steps/](steps/)）だけを読んでください。全部を読んでから始める必要はありません。
3. 各手順書にあるひな形（[templates/](../templates/)）を埋めながら進めます。
4. 困ったら、手順書の「困ったら」の欄を見て、エージェントかIPL担当に聞いてください。

## 守ってほしいこと（3つだけ）

1. **事実と予想を分ける**。出典（URL・特許番号など）を示せないことは「未確認」と書く。
2. **外れている証拠も探す**。自分の仮説に都合のよい情報だけを集めない。
3. **秘密の情報をAIに入れる前に確かめる**。出願前の発明や社外秘の情報は、社内規程で入力してよいか確認してから使う。

## 用語（最初に出てくるもの）

| 用語 | 意味 |
| --- | --- |
| 仮説 | 今の時点での見込み。調べた結果で変わってよい |
| 反証 | 仮説が外れていることを示す証拠。わざと探しにいく |
| ファーストユーザー | 最初に買ってくれる（使ってくれる）一社・一人 |
| エッジ情報 | あまり知られていない最先端の取り組みの情報で、事業機会に気づかせてくれるもの |
| ファミリー | 同じ発明を複数の国に出した特許のまとまり |
| FTO | 他社の特許を侵害せずに実施できるかの判断。このフローでは扱わず、知財部門・弁理士に相談する |
