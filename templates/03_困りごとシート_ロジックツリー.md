## 課題の3つの見方（任意：観点C）

| 見方 | 当てはまる課題 | 強い課題のしるし（あれば） | 根拠（出典）・状態（事実／予想／未確認） |
| --- | --- | --- | --- |
| ① 死活問題か（解決しないと事業・生活が立ち行かない） | | 予算がすでにある／期限がある／それなしには過ごせない | |
| ② まだ見つかっていない課題か（これから表に出る） | | 変化の時期が読める／先に気づいた人が少ない | |
| ③ 何が足りなくて解決できていないか（ラストワンピース） | | 誰がどこで止まっているか／足りない1つ／それを自社が持てそうか | |

必須は「死活問題か」に はい／いいえ／分からない で答えることだけ（STEP1 1-2）。この表は困りごとが弱そうなときに使う。確からしさは STEP7 で確かめる。
