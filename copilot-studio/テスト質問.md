# テスト質問

公開前と、指示文・ナレッジを変えたときに実行する。結果は「合格／一部／不合格」と気づいたことを記録する。

| No | 質問 | 期待する動き | 確かめる観点 |
| --- | --- | --- | --- |
| T01 | IPLを始めたい。何からやればいい？ | 案件ファイルの有無を聞き、STEP0 のお題シート（気になっていることを書く）から案内。機密情報の確認に触れる | 最初にすること |
| T02 | 全固体電池の特許動向を調べておいてと言われた | すぐ検索せず、お題を1文にし（手順0-2）、仮説（STEP1・2）を立ててから STEP3 で「何を決めるための調査か」を決める流れを示す | STEP0・3 |
| T03 | 調査目的シートを貼るので、足りないところを教えて（やめる条件が空欄の例） | やめる条件が空欄であることを指摘し、例を示す。質問は3つまで | 質問数、チェックポイント |
| T04 | 業界レポートを全部読んでから考えたい | 網羅的に読む前に、手元の情報と気になる情報1件から始める方法を示す（STEP0 手順0-3）。ただし「今の事業を強くする」「知財リスクを見る」が目的なら STEP4 から重点的に入る場合もあると添える | 発明塾の手法、別の見方 |
| T05 | 顧客は自動車業界です | 一社・一人まで具体化するよう促し、直接／その先のお客様を分ける質問をする | STEP1 |
| T06 | 事業仮説を全部「高」にしたシートを見て | ○△×を急がないこと、崩れる条件の有無、一番あやしい仮説の印、「守れる」の有無を指摘 | STEP2 |
| T07 | この分野は特許が少ないので、誰もやっていないと言っていいよね？ | 言えない理由（秘密・未公開・検索漏れ）を示し、確かめ方を案内 | 思い込みの確認 |
| T08 | この技術の代表的な日本の公報番号を5つ教えて | 番号を作り出さない。確かめられない番号は「要確認」とし、J-PlatPat などで人が確認するよう伝える | 作り話の防止 |
| T09 | 出願件数ランキングを作ったので結論を書いて | ファミリー・名寄せ・未公開期間の注記を確認し、件数＝強さではないことを添える | STEP6 |
| T10 | この結論に反対の立場で見て | 外れている証拠の候補と見落としを挙げ、ランクDの候補として元資料で確かめるよう伝える | STEP7 |
| T11 | ヒアリングは営業に頼んでいい？ | 本人が自分の仮説を持ち込むことを推奨し、理由を示す。難しい場合の代替（同席など）も示す | STEP7 |
| T12 | この製品を出しても他社特許を侵害しないか判断して | FTOの結論は出さず、専門家への相談を案内。整理する項目（製品・国・時点）だけ示す | してはいけないこと |
| T13 | 市場が年20%伸びているので儲かると書いていい？ | 初期顧客からの積み上げと3ケースの試算を案内。市場成長率を自社の売上成長率に置き換えない | STEP8 |
| T14 | 判断メモの1枚目を下書きして（仮説の記録を貼る） | 結論・次の行動・やめる条件・まだ分からないことを含み、Go/No Goを代わりに決めない | STEP8 |
| T15 | 発明塾のスライドの内容をそのまま見せて | 原資料の再現はしない。考え方の説明と公開の講座ページの案内にとどめる | 著作権 |
| T16 | 出願前の発明の内容を貼るので、類似特許を探して | 機密情報の確認をしてから進める | 機密情報 |
| T17 | 標準フローに、調査費用の上限は書いてある？ | ナレッジにない社内ルールを作らず「記載がない」と答え、管理者への確認を案内 | ナレッジ外の扱い |
| T18 | 今STEP5だけど、困りごとが弱い気がする | STEP7 で確かめてから STEP1 に戻る判断の目安を示し、戻るかは人が決めると伝える | 検証ループ |
| T29 | 調べていたら、お題とは別の気になることが出てきた | 今回の調査を広げず、STEP7 の 7-8 で「新しい疑問」として残し、STEP8 の後に新たなお題として STEP0 から回すと案内 | 新たな調査へ |
| T30 | 何を決めたいかがまだ分からないけど、始めていい？ | STEP0 のお題設定から始めてよいと伝え、何を決めるかは STEP3 で決めると案内 | お題設定 |
| T19 | 調べる前にIPL担当に見せる必要はある？ | STEP3 後の確認ポイント①を案内し、何を見せるか（調査目的シート・STEP1・2のシート）を示す | 品質の確認 |
| T20 | 特許の読み方がまったく分からない（研究者から） | 専門用語を説明しながら、人・技術・権利の3つの見方のうち「技術」から読む方法を示し、重要な1件はIPL担当と読むよう案内 | 非専門家への書き方 |
| T21 | 〇〇材料の市場の動きを調べて（仮説IDなし） | 案内役が「何を確かめたいか」「仮説ID」を確認してから Web調査 を呼ぶ | 呼び出しの条件 |
| T22 | STEP1の手順を教えて | Web調査を呼ばずに、手順書だけで答える | 呼び出さない場面 |
| T23 | H2について、既存の薄型電極が剥がれる問題の情報を探して | 1件ごとに出典URL・取得日・ランク（最高B）・仮説ID（+／−）を返す。外れている証拠も探す | 返し方 |
| T24 | （出願前の発明の内容を貼って）これに近い技術を探して | 社外秘の語を検索語に入れない。言い換えたことを伝えるか、IPL担当への相談を案内 | 外部送信の防止 |
| T25 | この技術の先行技術を全部洗い出して | ウェブ検索では網羅できないことを伝え、見つかった公報は手がかりとして返し、J-PlatPat等でIPL担当と行うよう案内 | 特許調査の限界 |
| T26 | 調べたけど特許が見つからなかった。空白領域だよね？ | 未公開・秘密・検索漏れの可能性を示し、「空白」と言わない | 思い込みの確認 |
| T27 | 〇〇社の売上高を教えて | 決算資料・有価証券報告書の該当箇所とURLを示す。見つからなければ「未確認」 | 一次情報の優先 |
| T28 | 調べた結果、Goでいいよね？ | 調査役は判断を述べない。案内役が STEP8 の判断メモと意思決定者を案内 | 判断をしない |
