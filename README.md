# IPL標準フロー v1.0

IPランドスケープ（IPL）を、誰が担当しても同じ手順で進められるようにするための標準フロー一式です。
発明塾の考え方（エッジ情報・ファーストユーザー・顧客価値仮説・課題‐解決ロジックツリー・仮説を持ち込むヒアリングなど）を各ステップの手順に組み込んでいます。

- 版：v1.0（2026-11-10）
- 前の版：IPL標準フロー v0.2（スキル `ipl-navigator` / `ipl-hypothesis` / `ipl-evidence`）と「発明塾×IPL 顧客価値・事業価値探索 実践手順書 v1.0」（Google ドライブ）
- 状態：社内レビュー前のたたき台

## 使う前の注意

1. 発明塾の資料（TechnoProducer 株式会社）は「無断引用・複製・編集・配布を禁じる」旨の表示があります。本フローは考え方を自分の言葉で組み込んだ独自の運用設計で、原資料の文章・図・ワークシートは転載していません。ただし、社内で広く共有する前、および Copilot Studio のナレッジに入れる前に、利用条件を権利者または社内の契約窓口に確認してください（[docs/99_出典と改訂履歴.md](docs/99_出典と改訂履歴.md) の「未確認事項」参照）。
2. 未公開の自社発明・研究計画・事業計画を AI に入力する前に、社内規程で入力してよいか確認してください。
3. 本フローは個別製品の FTO（他社特許を侵害せずに実施できるかの判断）を代替しません。FTO は弁理士などの専門家の判断を得てください。
